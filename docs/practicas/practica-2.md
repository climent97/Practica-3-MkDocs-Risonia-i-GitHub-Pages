# Pràctica 2 — GitHub i Pull Request

## Introducció

En aquesta pràctica es treballa amb Git i GitHub, utilitzant un repositori remot i un Pull Request.

## Procés realitzat

El treball inclou:

1. Clonar el repositori.
2. Modificar el fitxer `README.md`.
3. Crear un fork del repositori.
4. Canviar el repositori remot.
5. Pujar els canvis amb `git push`.
6. Comparar els canvis.
7. Crear un Pull Request.
8. Finalitzar el Pull Request.

## Fork i repositori remot

Després de crear el fork, es configura el repositori remot perquè els canvis es puguen enviar al repositori corresponent.

El procés permet treballar sobre una còpia del repositori i proposar els canvis mitjançant un Pull Request.

## Pull Request

Una vegada pujats els canvis, es comparen les modificacions i es crea el Pull Request.

El Pull Request permet revisar els canvis abans d'integrar-los en la branca principal.

## Conclusió

La pràctica permet treballar amb el flux bàsic de col·laboració entre Git i GitHub mitjançant forks, repositoris remots i Pull Requests.
