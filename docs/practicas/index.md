# Pràctiques

En aquesta secció es troba la documentació de les pràctiques realitzades.

## Pràctica 1 — Branques i unions

Treball amb branques de Git, unions (*merge*) i resolució de conflictes.

## Pràctica 2 — GitHub i Pull Request

Treball amb repositoris remots, fork, canvis i Pull Requests.

## Pràctica 3 — MkDocs i GitHub Pages

Creació del projecte de documentació amb MkDocs, configuració del tema Risonia i publicació en GitHub Pages.

## Pràctica 4 — Desplegament en GitHub Pages

Configuració de GitHub Actions per automatitzar la construcció i el desplegament del lloc web.
